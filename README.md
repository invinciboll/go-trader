### How does it work?
  - Go-Trader automates button inputs on android devices. It periodically captures screenshots via WebADB, uses OpenCV to locate specific buttons in those images, and then triggers touch input on the device, so no manual tapping is required.

### What about your data?
  - verything runs locally in your browser, no data is sent to any server.

### Prerequisites
  - USB Cable to connect your phone.
  - Android device with USB Debugging enabled. Learn how to [enable USB Debugging](https://developer.android.com/studio/debug/dev-options).
  - Chromium based Browser, like  [Google chrome](https://www.google.com/chrome).
